#UltraFocus 

Aplicação móvel de produtividade e gestão de foco desenvolvida no âmbito da PAP.

## Funcionalidades

- Sessões Pomodoro
- Sessões de Foco Personalizadas
- Sistema de Recompensas
- Sistema de Níveis
- Distintivos
- Sequências
- Estatísticas
- Tema claro e Escuro

## Tecnologias

- Java
- Android Studio
- FireBase
- Room Database
